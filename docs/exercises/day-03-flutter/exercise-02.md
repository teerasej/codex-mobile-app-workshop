# Exercise 2 — Navigation และ State


> **Day 3 · Flutter · 10:45–12:00**
>
> อ่าน [ภาพรวมและเงื่อนไขของวันนี้](/exercises/day-03-flutter/) ก่อนเริ่ม ใช้โฟลเดอร์ `service-desk-lite` เดิม และทำทีละ Practice


## Scenario

คนใช้ต้องกดดูใบงานเพื่อดูรายละเอียด แล้วกลับมาหน้ารายการเดิมได้

## Practice 1 — เปิดรายละเอียดใบงานที่เลือก

<PracticeIllustration asset="d03-e02-p01" eager />

**Primary target:** เดินทางจาก list ไป detail ของรายการที่แตะและกลับได้

### Steps

1. ใช้หน้ารายการที่เปิดได้จาก Exercise 1 ส่ง prompt นี้

   ~~~text
   ช่วยทำให้เวลาแตะใบงานใน My requests เราจะเห็นรายละเอียดของใบงานนั้น
   ทั้ง ID, ชื่อเรื่อง, รายละเอียด, หมวดหมู่และสถานะ แล้วกด Back กลับมาที่รายการได้
   ใช้หน้ารายการและข้อมูลตัวอย่างเดิมไปก่อนนะ

   ช่วยเขียนและรัน test ว่าแตะใบงานที่สองแล้วเห็น description ของใบงานที่สองจริง
   ~~~
2. เปิด preview แตะรายการที่สอง. เทียบ description/id กับ sample
3. กด Back แล้วเปิดรายการแรก. ตรวจว่าไม่ค้างข้อมูลรายการก่อนหน้า
4. ส่ง prompt เพื่ออธิบายสิ่งที่เพิ่งลอง

   ~~~text
   ที่เราเพิ่งลองแตะแล้วเปิดใบงาน แบบนี้เรียกว่า master-detail ใช่ไหม
   ช่วยเล่าสั้น ๆ ให้ดูว่าแอปส่งใบงานที่เราเลือกไปแสดงในหน้ารายละเอียดตรงไหน
   ~~~

**Checkpoint:** แตะรายการไหนได้รายละเอียดของรายการนั้น และ Back ทำงาน

## Practice 2 — เปลี่ยนตัวกรองด้วย State

<PracticeIllustration asset="d03-e02-p02" />

**Primary target:** เปลี่ยน UI ตามค่าที่ผู้ใช้เลือกโดยไม่แก้ source data ได้

### Steps

1. ส่ง prompt นี้เพื่อให้ตัวกรองเปลี่ยนเฉพาะสิ่งที่เห็น คล้ายเลือกมุมมองใน Microsoft Power Apps

   ~~~text
   อยากให้หน้า My requests เลือกดูทั้งหมดหรือดูเฉพาะสถานะ new, in_progress และ done ได้
   ช่วยบอกด้วยว่าตอนนี้เห็นกี่ใบ ถ้าไม่มีใบที่ตรง ให้มีข้อความแนะนำกับปุ่มย้อนกลับไปดูทั้งหมด
   ~~~
2. เลือกแต่ละสถานะ ใน fixture ของ `learner01` ต้องได้ **1 รายการต่อสถานะ** จด title/status ที่เห็นหนึ่งรายการ
3. เลือก **ทั้งหมด** หรือ reset ต้องกลับเป็น **3 รายการ** เปิดรายละเอียดเพื่อตรวจว่า status ไม่เปลี่ยน
4. ส่ง prompt ทดสอบกรณีว่างโดยไม่แก้ข้อมูลจริง

   ~~~text
   ช่วยเขียนและรัน test ให้หน่อยว่าเลือกสถานะแล้วเห็นใบงานถูกชุด และกด reset แล้วกลับมาเห็นทั้งหมด
   ใช้ข้อมูลตัวอย่าง learner01 เหมือนเดิม
   ~~~

**Checkpoint:** filter เปลี่ยนเฉพาะสิ่งที่แสดง ไม่เปลี่ยน status ของข้อมูล และ empty list ไม่ทำให้หน้าจอว่างแบบไม่มีคำอธิบาย
