## แอพเดียว เติบโตทุกวัน

พลจะพาพวกเราสร้างแอป **Service Desk Lite** สำหรับบริษัทสมมติ BrightDesk ใช้โฟลเดอร์เดิมตั้งแต่วันแรกจนจบหลักสูตร โดยหลักสูตรนี้ออกแบบให้พวกเราที่คุ้นเคยกับ Microsoft Power Apps และ PostgreSQL มาต่อยอดสู่การพัฒนาแอปด้วย Codex


## เรียนให้ตรวจงานเป็น

อ่านเป้าหมาย → ขอแผนจาก Codex → ตรวจและให้ทำทีละ Practice → ดู diff → ลอง Checkpoint จริง → บันทึกหลักฐาน → commit
